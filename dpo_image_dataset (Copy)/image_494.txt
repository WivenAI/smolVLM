Note explicative de l’onglet « comtpa » de la saisie des factures programme « fa
100 » : 

L'onglet "Compta" du programme "fa100" est conçu pour gérer les informations com
ptables liées à une facture. Voici une explication détaillée de la composition d
e cet onglet et de ses fonctionnalités :
Type de Facture :
Champ indiquant le type de facture (par exemple, MX).
Ce champ permet de catégoriser les factures pour une gestion appropriée dans le 
système comptable.
Numéro de Facture :
Champ affichant le numéro unique attribué à la facture (par exemple, 14010009).
Ce numéro est essentiel pour le suivi et la gestion des factures dans le système
.
Numéro de Pièce :
Champ affichant le numéro de pièce associé à la facture (par exemple, 111).
Ce numéro aide à relier la facture à des pièces comptables spécifiques pour une 
traçabilité accrue.
Numéro Client :
Champ affichant le numéro unique attribué au client (par exemple, 13601).
Ce numéro permet d'identifier le client dans le système et de lier les factures 
aux enregistrements client correspondants.
Langue :
Champ indiquant la langue utilisée pour la facture (par exemple, F pour français
).
Ce champ garantit que les documents sont générés dans la langue préférée du clie
nt.
Monnaie :
Champ indiquant la devise utilisée pour la facture (par exemple, CHF pour franc 
suisse).
La gestion de la monnaie est cruciale pour les transactions internationales et p
our s'assurer que les montants sont correctement convertis et enregistrés.
Compte Collectif :
Champ affichant le numéro de compte collectif associé à la facture (par exemple,
 1100).
Ce champ permet de regrouper les transactions similaires pour une gestion compta
ble simplifiée.
Conditions de Paiement :
Menu déroulant permettant de sélectionner les conditions de paiement (par exempl
e, 30_j_net).
Ce champ définit les termes de paiement de la facture, comme la durée de paiemen
t et les éventuels escomptes pour paiement anticipé.
Tarif :
Menu déroulant permettant de sélectionner le tarif applicable à la facture (par 
exemple, base).
Ce champ permet d'appliquer différents barèmes tarifaires selon les accords avec
 le client.
Libellé Comptable :
Champ pour entrer un libellé spécifique qui apparaîtra dans les enregistrements 
comptables.
Ce champ offre une description claire et concise des transactions pour faciliter
 la comptabilité.
Libellé Compte Débiteur :
Champ pour entrer un libellé spécifique pour le compte débiteur.
Ce champ aide à détailler les enregistrements liés aux débiteurs dans le système
 comptable.
Libellé Interne Pièce :
Champ pour entrer un libellé interne pour la pièce comptable.
Ce champ est utilisé pour des notes internes ou des descriptions supplémentaires
 pour une meilleure gestion des pièces comptables.
