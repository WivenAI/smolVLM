Note explicative de la saisie des demandes d’acompte programme « co503 » : 
Le programme co503 est conçu pour la copie des écritures comptables d'un lot à u
n autre au sein du système ERP. Ce programme est très utile pour la duplication 
de données comptables précises entre différents lots, facilitant ainsi les proce
ssus administratifs et la gestion financière. Voici comment il est structuré et 
son utilisation :
Structure du Programme
Source :
Lot : Identifie le lot source d'où les écritures comptables seront copiées.
N° : Spécifie le numéro d'identification spécifique au sein du lot source.
Exercice : Permet de sélectionner l'exercice financier auquel appartient le lot 
source.
Destination :
Créer un lot identique : Option pour créer automatiquement un lot identique à ce
lui de la source pour y copier les écritures.
Dans l'exercice : Permet de choisir l'exercice financier pour le nouveau lot ou 
la destination des écritures.
Lot : Permet de sélectionner ou d'entrer le lot de destination où les écritures 
seront copiées.
N° : Option de saisir un numéro spécifique pour le lot de destination si nécessa
ire.
Exercice : Sélectionne l'exercice financier de la destination.
