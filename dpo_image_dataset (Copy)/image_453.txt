Note explicative des gestions des échéanciers clients programme « db903 » : 
Le programme "db903" est destiné à la gestion des échéanciers clients. Il permet
 aux utilisateurs de configurer et de suivre différents types d'échéanciers en f
onction du comportement de paiement des clients. Voici un guide explicatif de se
s fonctionnalités et composants :
Configuration des Types d’Échéanciers :
Code et Désignation : Chaque échéancier est identifié par un code unique (par ex
emple, '>90jours' pour les paiements qui excèdent 90 jours) et une désignation q
ui décrit brièvement le type d'échéancier (par exemple, 'Supérieur à 90 jours').
Gestion des Détails d’Échéancier :
Pour chaque type d'échéancier, différentes configurations sont possibles pour gé
rer les postes ouverts (P.O.). Cela inclut les P.O. non échus, ceux échus depuis
 1-30 jours, 31-60 jours, et 61-90 jours.
Texte : Chaque intervalle peut être associé à un texte spécifique qui sera utili
sé dans les communications ou les rappels aux clients, ce qui permet de personna
liser le message en fonction de la période de retard.
Alertes et Impression :
Alerte : Des alertes peuvent être configurées pour chaque type de poste ouvert a
fin de notifier les utilisateurs lorsque certaines conditions sont remplies, com
me un retard de paiement dépassant un seuil spécifique.
Impression db320 : Indique si les détails de l'échéancier doivent être imprimés 
à partir d'une autre partie du système ERP, ce qui est utile pour la création de
 rapports ou de documents de suivi.
Autres Configurations :
Autres P.O. échus : Des configurations supplémentaires pour les paiements très e
n retard (plus de 90 jours), avec la possibilité d'ajouter des textes personnali
sés pour ces situations, améliorant ainsi la gestion des recouvrements.

Note explicative de la gestion des banques programme « bk100 » : 

Le programme bk100 est conçu pour gérer les informations bancaires au sein d'une
 entreprise. Voici un guide explicatif sur sa structure et ses fonctionnalités p
rincipales :
Gestion des Banques (bk/wk-bk100.w) : Cette interface permet de consulter et de 
gérer les données des banques associées à l'entreprise. Les informations telles 
que le nom de la banque, l'adresse, le numéro de clearing, et les détails du com
pte sont affichées dans un tableau central.
Fonctionnalités Clés :
Copie des banques d'une société vers une autre société : Cette fonction permet d
e copier les informations bancaires d'une société à une autre au sein du groupe,
 facilitant ainsi la gestion des données bancaires lors des expansions ou des re
structurations.
Importation et mise à jour du fichier des banques : Permet d'importer et de mett
re à jour les informations des banques à partir d'un fichier externe, garantissa
nt que les données restent actuelles et précises.
Sélection multi-critères : Cette option offre la possibilité de filtrer et de re
chercher des banques selon plusieurs critères, tels que le numéro de clearing ou
 le type de banque, afin de faciliter l'accès aux informations spécifiques.

Les utilisateurs peuvent modifier les détails existants des banques directement

La navigation entre différents ensembles de données peut être réalisée via des b
