Note explicative des imputations et extournes des ajustements programmes « co220
 » : 

Le programme "co220" est utilisé pour gérer les opérations d'imputation et d'ext
ourne des ajustements comptables dans le système ERP. Ce programme permet de con
trôler et d'effectuer des ajustements sur les écritures comptables pour une péri
ode donnée, avec la possibilité de générer des extournes si nécessaire. Voici un
e explication détaillée de la composition et des fonctionnalités de ce programme
.
Sélection des Paramètres d'Imputation/Extourne
Mois :
Ce menu déroulant vous permet de sélectionner le mois pour lequel vous souhaitez
 effectuer l'imputation ou l'extourne des ajustements. Il s'agit de la période c
omptable sur laquelle l'ajustement sera appliqué.
Avec Extourne :
Cette case à cocher permet de décider si l'ajustement doit être extourné. Si ell
e est cochée, une extourne (annulation de l'écriture précédente) sera générée po
ur le mois sélectionné, ce qui est utile lors de la correction ou du retour sur 
une imputation faite précédemment.
Informations Complémentaires
Date de Valeur :
Champ permettant de spécifier la date de valeur comptable de l'ajustement. La da
te de valeur est la date à laquelle l'ajustement prendra effet dans les comptes.
Type de Journal :
Sélectionnez le type de journal comptable auquel l'ajustement sera imputé. Le jo
urnal détermine la nature de l'écriture (par exemple, journal de vente, journal 
d'achat, etc.).
Type de Pièce :
Ce menu permet de spécifier le type de pièce comptable associée à l'ajustement (
par exemple, facture, note de crédit, etc.).
Numéro de Pièce :
Permet de saisir le numéro spécifique de la pièce comptable à laquelle l'ajustem
ent est lié. Cela facilite le suivi et l'identification des ajustements dans les
 registres comptables.
Intitulé du Lot :
Champ pour entrer un intitulé ou une description du lot d'ajustements. Ce champ 
est utile pour regrouper et identifier plusieurs ajustements sous une même dénom
ination.

Note explicative de la différence de change C.G programme « co260 » : 

Le programme "co260" est conçu pour gérer les différences de change en Comptabil
ité Générale (CG). Il permet de comptabiliser les écarts de change qui survienne
nt lors des transactions en devises étrangères en fonction des variations des ta
ux de change. Voici une explication détaillée de la composition et des fonctionn
alités de ce programme.
Sélection au Niveau des Comptes
Tous les Comptes C.G. :
Cette option permet d'inclure tous les comptes de Comptabilité Générale dans l'é
valuation des différences de change. Vous avez également la possibilité de sélec
tionner des comptes spécifiques soit par ordre alphabétique, soit par ordre numé
rique pour une gestion ciblée.
Choix du Type de Journal et Type de Pièce
Type de Journal et Type de Pièce :
Type de Journal : Vous sélectionnez ici le journal comptable dans lequel les écr
itures de différences de change seront enregistrées. Par exemple, "Journal opéra
tion diverse" est utilisé pour enregistrer les ajustements divers en CG.
Type de Pièce : Indiquez le type de document ou de transaction qui sera utilisé 
pour enregistrer la différence de change (par exemple, "Opération diverse").
Date de Pièce et Date de Valeur
Date de Pièce et Date de Valeur :
Date de Pièce : Spécifiez la date à laquelle la pièce comptable est générée.
Date de Valeur : Indiquez la date à laquelle l'écriture prendra effet dans les c

Choix des Taux de Change à Appliquer
Taux de Change à Appliquer :
Taux du Jour : Utilise le taux de change en vigueur à la date de la transaction 
ou à une date spécifiée.
Taux Fixes : Applique un taux de change prédéfini, qui peut être utilisé pour de
s transactions répétitives ou des contrats avec des taux fixes.
