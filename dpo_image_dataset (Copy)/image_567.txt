Variante fa662 :

NB : Cette variante est spécifique à certains clients

Le programme FA662 permet uniquement d' attribuer un numéro de facture et d'envo
yer le document à un client final (Edition).

Avantage : en cas de changement de montant, rabais etc.. il n'est pas nécessaire
 d'extourner l'écriture (pas de comptabilisation).

Exemple de flux :

1) FV100 : Création facture pour Fr. 200.-
2) FA662 : Edition de la facture (pas d'imputation)

Puis, le montant passe de Fr. 200.- à Fr. 140.-

3) FV100 : Modification du montant à Fr. 140.-
4) FA661 : Edition de la facture avec mise à jour => la facture est imputée en c
omptabilié

Le programme "fa900" est utilisé pour gérer les tables simples dans le système E

Sur la partie gauche de l'écran, vous avez une liste de types de tables que vous

Au centre de l'écran, vous avez une vue tableau des éléments de la table sélecti

No Code : Le code unique de l'élément dans la table.
Désignation : La désignation principale de l'élément.
Désignation 2 : Une désignation supplémentaire pour l'élément.

Lorsque vous sélectionnez un élément dans la liste, ses détails apparaissent dan

Utilisation
