Les champs d’entête spécifiques au programme fa100 :


« Type de facture » : Liste déroulante des différents types de factures pouvant 
êtres traités dans les programmes fa100. (voir paramétrage dans fa901).


 « Factures non imputées » : : Possibilité de filtrer que les factures non-imput
ées en comptabilité (donc les factures en cours n’ayant pas encore de numéro de 
facture, mais seulement un numéro de pièce).
« Imputées » : Possibilité de filtrer que les factures imputées en comptabilité 
et ayant un de numéro de facture.
« Toutes » Permet de filtrer les deux critères défini ci-dessus.
« Mes factures » Possibilité de filtrer que les factures ayant le même Id. que c
elui de la personne qui a créé ou modifié la facture.
« Toutes les factures » Possibilité de filtrer toutes les factures quelque soit 
l’Id. des personnes qui ont créé ou modifié les factures.
 Permet d’afficher la liste des factures en mode « plein écran ».

Note explicative de la saisie des factures programme « fa100 »
Le programme "fa100" est un outil de facturation utilisé dans un système ERP pou
r créer, modifier, et gérer les factures. Voici une explication détaillée de sa 
composition et de ses fonctionnalités :
Navigation et Filtres :
Type de facture : Permet de sélectionner le type de facture à afficher ou à édit
er, par exemple "Contrats d'entretien". Ce filtre aide à organiser et gérer les 
factures par catégories spécifiques.
Filtres de statut : Options pour afficher les factures selon leur statut : factu
res non imputées, imputées, ou toutes. Il y a également des options pour affiche
r "Mes factures" ou "Toutes".
Tableau des Factures :
Colonnes principales :
Type : Type de facture, par exemple CE pour Contrat d'entretien.
N° pièce : Numéro de la pièce, identifiant unique de la facture.
N° facture : Numéro de la facture associée.
N° client et Désignation : Identifiant et nom du client.
Ident. : Identifiant de la facture.
Date de pièce et N° de bon : Date et numéro du bon de commande associé.
Compte C.A. : Compte de chiffre d'affaires lié à la facture.
N° affaire : Numéro d'affaire ou projet associé.
Concerné : Description de ce que la facture concerne, par exemple "vente prestat
ions".
Montant TTC : Montant total toutes taxes comprises.
Note explicative de l’onglet « Base » de la saisie des factures programme « fa10
0 » : 
Base :
Type de facture : Type de facture, par exemple CE.
N° de facture : Numéro de la facture (à compléter).
Date de valeur : Date de valeur de la facture.
N° de pièce : Numéro de la pièce.
Informations Client :
Immeuble : Référence de l'immeuble.
Client : Nom du client.
Succursale : Succursale ou organisation internationale liée.
Compte CA : Compte de chiffre d'affaires associé.
Détails Additionnels :
Concerné : Description de ce que la facture concerne.
V. Référence : Référence de la vente (à compléter).
Livraison : Détails de la livraison (à compléter).
Responsable : Nom du responsable de la facture.
Compta : Onglet pour les détails comptables spécifiques.
Impres/Adress : Onglet pour les informations d'impression et d'adresse.

Totaux et Détails Financiers :
Remise : Montant de la remise appliquée.
HT : Montant hors taxe.
TVA : Montant de la TVA.
TTC : Montant total toutes taxes comprises.







Note explicative de l’onglet « comtpa » de la saisie des factures programme « fa
100 » : 

L'onglet "Compta" du programme "fa100" est conçu pour gérer les informations com
ptables liées à une facture. Voici une explication détaillée de la composition d
e cet onglet et de ses fonctionnalités :
Type de Facture :
Champ indiquant le type de facture (par exemple, MX).
Ce champ permet de catégoriser les factures pour une gestion appropriée dans le 
système comptable.
Numéro de Facture :
Champ affichant le numéro unique attribué à la facture (par exemple, 14010009).
Ce numéro est essentiel pour le suivi et la gestion des factures dans le système
.
Numéro de Pièce :
Champ affichant le numéro de pièce associé à la facture (par exemple, 111).
Ce numéro aide à relier la facture à des pièces comptables spécifiques pour une 
traçabilité accrue.
Numéro Client :
Champ affichant le numéro unique attribué au client (par exemple, 13601).
Ce numéro permet d'identifier le client dans le système et de lier les factures 
aux enregistrements client correspondants.
Langue :
Champ indiquant la langue utilisée pour la facture (par exemple, F pour français
).
Ce champ garantit que les documents sont générés dans la langue préférée du clie
nt.
Monnaie :
Champ indiquant la devise utilisée pour la facture (par exemple, CHF pour franc 
suisse).
La gestion de la monnaie est cruciale pour les transactions internationales et p
our s'assurer que les montants sont correctement convertis et enregistrés.
Compte Collectif :
Champ affichant le numéro de compte collectif associé à la facture (par exemple,
 1100).
Ce champ permet de regrouper les transactions similaires pour une gestion compta
ble simplifiée.
Conditions de Paiement :
Menu déroulant permettant de sélectionner les conditions de paiement (par exempl
e, 30_j_net).
Ce champ définit les termes de paiement de la facture, comme la durée de paiemen
t et les éventuels escomptes pour paiement anticipé.
Tarif :
Menu déroulant permettant de sélectionner le tarif applicable à la facture (par 
exemple, base).
Ce champ permet d'appliquer différents barèmes tarifaires selon les accords avec
 le client.
Libellé Comptable :
Champ pour entrer un libellé spécifique qui apparaîtra dans les enregistrements 
comptables.
Ce champ offre une description claire et concise des transactions pour faciliter
 la comptabilité.
Libellé Compte Débiteur :
Champ pour entrer un libellé spécifique pour le compte débiteur.
Ce champ aide à détailler les enregistrements liés aux débiteurs dans le système
 comptable.
Libellé Interne Pièce :
Champ pour entrer un libellé interne pour la pièce comptable.
Ce champ est utilisé pour des notes internes ou des descriptions supplémentaires
 pour une meilleure gestion des pièces comptables.
