Note explicative du contrôle d’équilibre programme « cg399 » : 

Le programme "cg399" est un outil essentiel pour effectuer des contrôles d'équil
ibre dans la Comptabilité Générale (CG). Il permet de vérifier que toutes les éc
ritures comptables sont bien équilibrées sur une période donnée, garantissant ai
nsi l'intégrité des comptes. Voici une explication détaillée de la composition e
t des fonctionnalités de ce programme.
1. Sélection des Périodes
Période de/à :
Cette section permet de définir la plage de dates sur laquelle le contrôle d'équ
ilibre sera effectué. Vous sélectionnez la date de début et la date de fin de la
 période comptable à vérifier. Cette fonctionnalité est cruciale pour s'assurer 
que les balances sont justes pour une période spécifique, comme une clôture mens
uelle, trimestrielle ou annuelle.
2. Démarrage du Contrôle
Lancer le Contrôle :
Après avoir sélectionné la période, vous pouvez démarrer le processus de contrôl
e en cliquant sur le bouton de validation (représenté par la coche verte). Le pr
ogramme analysera toutes les écritures comptables pour la période spécifiée, vér
ifiant que les débits et crédits sont équilibrés.
3. Message de Confirmation
Confirmation de la Fin du Contrôle :
Une fois le contrôle terminé, une fenêtre de message s'affiche pour confirmer qu
e le processus est achevé. Ce message indique que le programme a terminé de véri
fier toutes les écritures pour la période sélectionnée. Si aucune différence cum
ulée n'est détectée (différence cumulée CV = 0.00), cela signifie que les compte
s sont équilibrés.

Note explicative de l’onglet MAJ du programme « xstes » pour l'ensemble des opér
ations liées à la comptabilisation externe, ou "différée" : 
Le programme "xstes" dans l'ERP est dédié à la gestion des sociétés et permet de
 configurer divers paramètres comptables pour chaque entité juridique gérée dans
 le système. L'onglet "MAJ" (Mise à Jour) de ce programme joue un rôle crucial d
ans la configuration des méthodes de comptabilisation, notamment la comptabilisa
tion différée ou directe. Ce chapitre se concentre sur la manière dont ces param
ètres sont définis et appliqués.
Paramètres de Comptabilisation
Comptabilisation Différée :
MAJ co100 à co104 on line : Ce paramètre active la mise à jour en ligne (différé
e) pour les programmes de comptabilité générale, tels que "co100" à "co104". En 
sélectionnant cette option, les écritures ne sont pas immédiatement intégrées da
ns les comptes, mais sont d'abord stockées et peuvent être validées ultérieureme
nt.
MAJ co210 on line : De manière similaire, ce paramètre gère la mise à jour diffé
rée pour les provisions, ce qui permet de contrôler les écritures avant qu'elles
 n'affectent les comptes finaux.
MAJ co220 on line : Ce paramètre concerne les ajustements, qui peuvent être réal
isés de manière différée pour permettre des vérifications supplémentaires avant 
la comptabilisation finale.
Comptabilisation Directe :
MAJ situations on line (db812) : Cette option permet une mise à jour immédiate d
es situations comptables en ligne, intégrant directement les données dans les co
mptes sans besoin de validation ultérieure.
MAJ paiements fournisseurs on line (cr600) : Ce paramètre assure que les paiemen
ts fournisseurs sont directement comptabilisés, garantissant une rapidité dans l
a mise à jour des comptes fournisseurs.
MAJ salaires on line (sa160) : Ce paramètre permet de comptabiliser directement 
les salaires, ce qui est essentiel pour maintenir des comptes de paie précis et 
à jour.
Utilisation Pratique
Configuration de la Comptabilisation Différée
Lorsque vous avez besoin de vérifier les écritures comptables avant de les intég
rer définitivement dans les comptes, sélectionnez les options de "MAJ on line" p
our les programmes pertinents. Cela vous donne un contrôle supplémentaire sur le
 processus comptable, permettant une validation manuelle avant l'intégration.
Configuration de la Comptabilisation Directe
Pour les processus qui nécessitent une mise à jour immédiate des comptes, tels q
ue les paiements ou les salaires, configurez les paramètres pour une mise à jour
 directe. Cela garantit que les écritures sont immédiatement prises en compte, c
e qui est crucial pour les opérations nécessitant une précision et une rapidité 
accrues.

Note explicative des imputations des écritures externes programme « co110 » : 

Le programme "co110" est utilisé pour l'imputation des écritures externes dans l
e système de comptabilité. Il permet de traiter les données provenant d'applicat
ions externes et de les intégrer dans la comptabilité générale de manière effica
ce et sécurisée. Voici une explication détaillée de la composition et des foncti
onnalités de ce programme.
Fonctionnalités Principales
Sélection de l'Application Externe à Traiter :
Application à traiter : Cette liste déroulante permet de sélectionner l'applicat
ion externe dont les écritures doivent être imputées. Les applications externes 
peuvent être des systèmes ou des modules externes qui génèrent des lots d'écritu
res à intégrer dans la comptabilité générale. La sélection correcte de l'applica
tion est essentielle pour garantir que les bonnes données sont traitées.
Fermeture du Lot en Fin de Traitement :
Coche pour fermer le lot : En cochant cette option, le système ferme automatique
ment le lot une fois que toutes les écritures ont été imputées. Cette fonctionna
lité est importante pour sécuriser les données, empêchant toute modification ult
érieure du lot une fois qu'il a été traité et intégré dans les comptes.
Sélection des Lots à Traiter :
Lot(s) : Cette section permet de sélectionner un ou plusieurs lots d'écritures p
rovenant de l'application externe à traiter. En cliquant sur cette option, vous 
pouvez afficher tous les lots disponibles pour l'application sélectionnée et cho
isir ceux qui doivent être intégrés dans la comptabilité. La sélection multiple 
permet de traiter plusieurs lots en une seule opération, ce qui améliore l'effic
acité du processus.
