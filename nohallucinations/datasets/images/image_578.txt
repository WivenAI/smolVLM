res, existantes ou terminées.

Affaires existantes : Affiche uniquement les offres qui ont été validées et qui 
sont en cours de traitement.
Offres terminées : Affiche uniquement les offres qui ont été clôturées.
Les colonnes incluses sont :
Désignation affaire : La désignation de l'affaire liée à l'offre.
Numéro : Le numéro de l'offre.
Client Désignation client : Le nom du client.

Npa : Le code postal du chantier.

Zone : La zone géographique du chantier.
Evts : Les éventuelles remarques ou événements liés à l'offre.
