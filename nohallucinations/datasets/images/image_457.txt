Gestion des sites db904 : 


Note explicative des gestions des sites programme « db904 » : 
Le programme "db904" est conçu pour gérer et configurer des sites ou des emplace
ments spécifiques, notamment pour les entreprises ayant plusieurs sites ou néces
sitant une gestion détaillée de différents lieux ou divisions. Voici une explica
tion détaillée de ses fonctionnalités et de sa composition :
Gestion des Sites :
No Code et Désignation : Chaque site est identifié par un numéro de code et une 
désignation qui le décrit, comme "1 BAL" pour "Client balance". Cela permet une 
identification rapide et claire du site concerné dans la gestion des opérations 
ou des rapports financiers.
Configuration de Site :
Import : La colonne "Import" indique si les données relatives à ce site peuvent 
être importées ou intégrées automatiquement à partir de sources externes, facili
tant la mise à jour et le maintien des informations sans saisie manuelle répétit
ive.
Fonctionnalités du Programme :
Modifier, Rétablir, Ajouter, Copier, Effacer, Annuler : Ces boutons offrent une 
gamme complète d'actions que l'utilisateur peut effectuer sur les données des si
tes, permettant une gestion flexible et dynamique des informations. Les utilisat
eurs peuvent facilement ajouter de nouveaux sites, modifier les détails des site
s existants, copier les configurations pour de nouveaux emplacements, ou supprim
er les sites obsolètes.
Multilinguisme :
Langue : Permet de choisir la langue de saisie ou d'affichage pour les données d
u site, assurant que le système peut être utilisé efficacement dans des environn
ements multilingues ou multinationaux.

Note explicative de la gestion des banques programme « bk100 » : 

Le programme bk100 est conçu pour gérer les informations bancaires au sein d'une
 entreprise. Voici un guide explicatif sur sa structure et ses fonctionnalités p
rincipales :
Gestion des Banques (bk/wk-bk100.w) : Cette interface permet de consulter et de 
gérer les données des banques associées à l'entreprise. Les informations telles 
que le nom de la banque, l'adresse, le numéro de clearing, et les détails du com
pte sont affichées dans un tableau central.
Fonctionnalités Clés :
Copie des banques d'une société vers une autre société : Cette fonction permet d
e copier les informations bancaires d'une société à une autre au sein du groupe,
 facilitant ainsi la gestion des données bancaires lors des expansions ou des re
structurations.
Importation et mise à jour du fichier des banques : Permet d'importer et de mett
re à jour les informations des banques à partir d'un fichier externe, garantissa
nt que les données restent actuelles et précises.
Sélection multi-critères : Cette option offre la possibilité de filtrer et de re
chercher des banques selon plusieurs critères, tels que le numéro de clearing ou
 le type de banque, afin de faciliter l'accès aux informations spécifiques.
Modification et Ajout :
Les utilisateurs peuvent modifier les détails existants des banques directement 
dans le tableau en utilisant le bouton 'Modifier'.
Il est également possible d'ajouter de nouvelles banques en utilisant le bouton 
'Ajouter', permettant à l'entreprise d'étendre ses opérations bancaires selon le
s besoins.
Options de Configuration et de Navigation :
Le programme inclut des boutons fonctionnels tels que 'Copier', 'Effacer' pour g
érer facilement les données des banques.
La navigation entre différents ensembles de données peut être réalisée via des b
outons ou des commandes intégrées qui permettent une manipulation efficace et ra
pide des informations.
