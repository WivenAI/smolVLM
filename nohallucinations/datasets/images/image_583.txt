Note explicative du plan comptable programme « cg100 » : 

Le programme "cg100" est un outil intégré dans le système ERP destiné à la gesti
on du plan comptable. Voici une description détaillée de ses composants et fonct
ionnalités pour une compréhension claire et exhaustive :
1. Volet de Visualisation du Compte
Le volet de visualisation du compte est une section du programme où l'utilisateu
r peut sélectionner et afficher les détails d'un compte spécifique. Cela permet 
de voir en un coup d'œil les informations essentielles d'un compte comptable, y 
compris les transactions et les soldes actuels.
2. Solde Actuel du Compte
Le solde actuel du compte est une information cruciale affichée en haut de la fe
nêtre. Il indique le montant disponible ou dû dans le compte sélectionné. Cette 
valeur est mise à jour en temps réel en fonction des transactions enregistrées d
ans le système.
3. Onglet "Liste"
L'onglet "Liste" est une interface de visualisation où sont listés tous les comp
tes du plan comptable. Voici une description détaillée des colonnes et des infor
mations affichées :
Numéro : Le numéro unique attribué à chaque compte, utilisé pour l'identificatio
n et le suivi.
Intitulé court : Un nom abrégé du compte pour une identification rapide.
Monnaie : La devise dans laquelle les transactions du compte sont effectuées.
Type : Indique la nature du compte (Actif, Passif, etc.).
Intitulé : Le nom complet du compte, donnant plus de détails que l'intitulé cour
t.
Intitulé (suite) : Informations supplémentaires ou descriptions étendues du comp
te.
Compte C.A. : Référence au compte de Centre d'Analyse (C.A.) si applicable.
Genre de frais : Type de dépenses associées au compte, le cas échéant.
Fonctionnalités Clés :
Navigation et Sélection :
Type de compte : Un filtre permettant de sélectionner un type de compte spécifiq
ue pour une visualisation plus ciblée.
Saisie du compte : Une zone de saisie pour entrer directement le numéro de compt
e que l'utilisateur souhaite consulter.
Visualisation des Soldes :
Soldes actuels en monnaie : Affiche le solde actuel dans la devise principale du
 compte.
En contre-valeur : Montre la valeur équivalente dans une autre devise, facilitan

Gestion des Comptes :
