Note explicative de la génération de factures programme « bt120 » : 
Le programme "bt120" est conçu pour la gestion et la génération de factures dans
 un système ERP. Ce programme permet d'importer et de traiter des données de fac
turation de manière efficace et organisée. Voici une explication détaillée de la
 composition du programme et de ses fonctionnalités :
Composition du Programme "bt120"
Sélection des Données à Importer :
Type de facture : Menu déroulant permettant de sélectionner le type de facture à
 traiter, par exemple "300.10 Balance".
Bons du et au : Champs de date pour définir la période des bons à inclure dans l
'import.
Mois : Sélection du mois pour lequel les factures doivent être générées.
Filtrage des Données :
Client : Champ permettant de filtrer les enregistrements par client spécifique.
Chantier : Champ permettant de filtrer les enregistrements par chantier spécifiq
ue.
Statut des factures : Options pour sélectionner les enregistrements "A facturer"
, "Facturées" ou "Désactivées".
Options de filtrage : Options supplémentaires pour filtrer les données par "Tous
", "Départ", "Franco", ou "Neutre".
Gestion des Enregistrements :
Numéro import : Champ pour entrer le numéro de l'import.
N° bon : Champ pour entrer le numéro du bon.
Numéro ligne : Champ pour entrer le numéro de ligne.
Date : Champ pour entrer la date associée.
Client : Champ pour entrer ou sélectionner le client.
Chantier : Champ pour entrer ou sélectionner le chantier.
Véhicule : Champ pour entrer ou sélectionner le véhicule.
Article : Champ pour entrer ou sélectionner l'article.
Zone : Sélection de la zone concernée.
Quantité : Champ pour entrer la quantité.

Note explicative des statistiques de vente programme « sc150 » : 
Le programme "sc150" est conçu pour générer des statistiques de vente par client
 et exporter ces données vers Excel. Voici une explication détaillée de la compo
sition du programme et de ses fonctionnalités :
Composition du Programme "sc150"
Filtres de Sélection :
Type de facture : Menu déroulant permettant de sélectionner le type de facture à
 inclure dans les statistiques (toutes, imputées, non imputées).
Dates de début et de fin : Champs pour entrer les dates de début et de fin de la
 période pour laquelle les statistiques doivent être générées.
Onglets de Sélection :
Sél. Client : Permet de sélectionner les clients spécifiques pour lesquels génér
er les statistiques.
Sél. Article : Permet de sélectionner les articles spécifiques pour lesquels gén
érer les statistiques.
Sél. CG/CA : Permet de sélectionner les comptes généraux ou auxiliaires spécifiq
ues pour lesquels générer les statistiques.
Options de Résultat :
Modifier les critères : Bouton permettant de modifier les critères de sélection 
des données.
Interroger selon critères : Bouton permettant de lancer l'interrogation et affic
her les résultats selon les critères définis.
Tout exporter vers Excel : Bouton permettant d'exporter toutes les données affic
hées vers un fichier Excel.
Exporter une sélection de lignes : Bouton permettant d'exporter uniquement une s
élection de lignes vers Excel.
Affichage des Données :
Tableau principal : Affiche les résultats de l'interrogation selon les critères 
définis. Les colonnes incluent :
No prov. : Numéro provisoire.
No Facture : Numéro de la facture.
No-débiteur : Numéro du débiteur.
Intitulé court : Intitulé court du débiteur.
Date réf. : Date de référence.
Code catalogue : Code du catalogue.
Catalogue : Nom du catalogue.
Code : Code de l'article.
Désignation article : Désignation de l'article.
Quantité : Quantité vendue.
Unité : Unité de mesure.

Note explicative de l’onglet « adr.commande » de la gestion des factures ventes 
programme « fv100 » : 
L'onglet "Adr. Commande" du programme "fv100" permet de gérer les informations l
iées à l'adresse de commande pour chaque facture de vente. Voici une note explic
ative fonctionnelle détaillant la composition de cet onglet :
Type de Facture et Numéro de Pièce :
Ces champs sont repris de l'onglet principal et identifient le type de facture (
exemple : FI pour Facture Intervention) et le numéro de pièce associé (exemple :
 1013).
Adresse de la Commande :
Cet espace est dédié à l'entrée des informations de l'adresse de la commande. Le
s champs sont les suivants :
Titre adresse : Titre de l'adresse (exemple : Régie).
Nom 1 : Nom principal de l'adresse (exemple : Centre SA).
Nom 2, Nom 3, Nom 4 : Champs supplémentaires pour entrer des informations additi
onnelles sur l'adresse si nécessaire.
Rue 1, Rue 2 : Adresse de la rue où se situe l'organisation ou la personne à qui
 la facture est adressée (exemple : Rue de la Madeleine 8).
No postal : Code postal de l'adresse (exemple : 1204).
Localité : Ville ou localité de l'adresse (exemple : Genève).
Pays : Pays de l'adresse, indiqué par son code et son nom (exemple : CH Suisse).
Bouton "Depuis une adresse" :
Ce bouton permet de remplir automatiquement les champs d'adresse en utilisant un
e adresse déjà existante dans le système. Cela facilite l'entrée des données et 
assure la cohérence des informations d'adresse.
Fonctionnalités Principales
Saisie et Gestion des Adresses de Commande :
L'utilisateur peut entrer toutes les informations pertinentes pour l'adresse de 
commande directement dans les champs prévus à cet effet, garantissant une gestio
n précise et cohérente des adresses associées aux commandes.
Automatisation et Efficacité :
L'option "Depuis une adresse" permet de remplir rapidement les champs d'adresse 
en utilisant des données déjà disponibles, améliorant ainsi l'efficacité et rédu
isant les erreurs potentielles.
