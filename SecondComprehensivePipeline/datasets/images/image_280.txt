Table simple soumission so900 : 

Note explicative de la table simple des soumissions programme « so900 » : 
Le programme "so900" est une interface de gestion des tables simples, probableme
nt destinée à la maintenance de données de base dans un système ERP pour les mod
ules de soumission ou de gestion de projet.

Type: Affiche différentes catégories de données, telles que les produits ou les

table.

Numéro: Pour saisir ou rechercher un numéro d'identification spécifique dans la 
table.
Code: Pour entrer ou rechercher le code associé à une entrée.
Désignation (1): Pour entrer ou modifier la désignation principale de l'entrée.
(2): Pour entrer ou modifier la désignation secondaire.

pplémentaires.
