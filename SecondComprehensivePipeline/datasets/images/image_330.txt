Note explicative de l’onglet « Liste » de la gestion des débiteurs programme « d
b100 » 
Le programme db100, dédié à la gestion des débiteurs, comporte un onglet "Compte
" très utile pour le suivi détaillé des informations spécifiques à chaque débite
ur. Voici une explication détaillée de ses composants et de son fonctionnement :
Détails du Compte :
Numéro : Le numéro identifiant unique du débiteur dans le système.
Intitulé de recherche : Un titre ou une référence rapide utilisée pour identifie
r le débiteur lors des recherches.
Numéro d'adresse : Numéro spécifique attribué à l'adresse du débiteur.
Monnaie : La monnaie dans laquelle les transactions du débiteur sont gérées.
Conditions de paiement : Conditions sous lesquelles les paiements sont acceptés 
de ce débiteur.
T.V.A. : Informations sur la taxe sur la valeur ajoutée applicable, y compris si
 la taxe est incluse, et autres spécificités relatives à l'organisation internat
ionale.
Gestion de Groupe et Collectif :
Collectif : Catégorie de collectif à laquelle le débiteur appartient, avec une o
ption pour changer de collectif si nécessaire.
Groupe clients : Groupe auquel le débiteur est associé pour faciliter la gestion
 segmentée.
Sucursale : Branche ou division de l'entreprise à laquelle le débiteur est assoc
ié.
Groupe statistique : Groupe pour lequel des données statistiques sont collectées
.
Détails de Facturation :
Adresse de facturation : Où les factures doivent être envoyées.
Tarif : Identifie le tarif spécifique appliqué au débiteur.
BVR : Numéro de référence pour le bulletin de versement (utilisé en Suisse).
Factures PDF : Si les factures doivent être générées en format PDF.
Factures groupées : Indique si les factures pour ce débiteur doivent être groupé
es.
Gestion des Risques et Crédits :
Limite de crédit : Montant maximal de crédit autorisé pour ce débiteur.
Options Additionnelles :
Édition des appels par chantier : Détermine si les appels de paiement doivent êt
re spécifiques à chaque chantier.
Est un compte de regroupement : Indique si le compte est utilisé pour regrouper 
plusieurs débiteurs sous une seule entité pour la facturation ou les rapports.

Note explicative de l’onglet « rappel » de la gestion des débiteurs programme « 
db100 » :
L'onglet "Rappel" du programme db100, qui fait partie du système de gestion des 
débiteurs, permet de configurer et de gérer les rappels de paiement pour les cli
ents. Voici une description détaillée de ses composants principaux :
Paramètres des Rappels :
Référence rappels : Identifiant utilisé pour les rappels.
Nombre de rappel(s) maximum : Le nombre maximum de rappels qui peuvent être envo
yés à un débiteur.
Code pour impression rappel : Codes utilisés pour personnaliser les rappels impr
imés selon le type de rappel (1 à 7, par exemple).
Titre rappel : Le titre donné au rappel, souvent utilisé pour attirer l'attentio
n du débiteur.
Entête rappel : Texte placé en haut de chaque rappel, généralement utilisé pour 
introduire la raison du rappel.
Salutations rappel : Formulation de clôture du rappel, pour maintenir la polites
se et la professionnalité.
Options de Rappel :
Joindre les factures au rappel : Permet d'attacher les copies des factures impay
ées aux rappels pour référence du débiteur.
Valable si édition des factures en PDF : Indique si cette option doit être utili
sée uniquement lorsque les factures sont éditées en format PDF.
Gestion des Contenus Litigieux :
En contentieux : Cette option, lorsqu'elle est cochée, marque le rappel comme ét
ant lié à un contentieux, ce qui peut affecter la manière dont le rappel est tra
ité et suivi.
Sélection 'Contentieux' : Permet de choisir des rappels spécifiquement pour les 
situations de contentieux, facilitant la gestion des cas litigieux.

Note explicative de l’onglet « historique » de la gestion des débiteurs programm
e « db100 » : 
L'onglet "Historique" du programme db100, qui fait partie de la gestion des débi
teurs, permet de visualiser et de suivre l'historique des transactions financièr
es pour chaque compte de débiteur. Voici une explication de ses principales fonc
tionnalités :
Tableau des Transactions :
N° écriture : Numéro d'identification de l'écriture comptable.
Lot N° de P.O. : Numéro du lot de la pièce d'ordre (P.O.), associé à l'écriture.
Date Valeur : La date à laquelle la transaction prend effet financièrement.
N° de pièce : Numéro de la pièce comptable.
Date pièce : Date d'émission de la pièce comptable.
Libellé de l'écriture : Description ou libellé associé à l'écriture comptable.
Montant en monnaie : Montant de la transaction dans la monnaie de base.
Montant en contre-valeur : Montant de la transaction dans une autre monnaie, si 
applicable.
Montant encaissement : Montant effectivement encaissé, si différent du montant f
acturé.
Solde : Solde actuel du compte après cette écriture.
Fonctionnalités de Filtrage et de Recherche :
Filtre sur date-valeur : Permet de filtrer les écritures basées sur la date à la
quelle elles ont pris effet, facilitant la recherche de transactions spécifiques
.
Clic droit : Offre des options supplémentaires pour gérer ou modifier les écritu
res, telles que des corrections ou des ajustements.
