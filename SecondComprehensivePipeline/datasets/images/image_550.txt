Note explicative d’Edition des factures programme « fa661 » : 
Le programme "fa661" est conçu pour l'édition des factures. Voici comment il est
 structuré et comment vous pouvez l'utiliser efficacement :
1. Sélection des Types de Facture
Type de facture : Permet de sélectionner le type de facture à éditer, par exempl
e, "Demande Acompte Simple".
Succursale(s) : Vous pouvez choisir toutes les succursales ou en sélectionner un
e spécifique pour laquelle les factures seront éditées.
2. Sélection par Responsable
Group(e)s clients : Sélectionner le ou les groupes de clients concernés par l'éd
ition des factures.
Utilisateurs : Filtrer par utilisateur pour voir les factures créées par une per
sonne spécifique.
Responsable(s) : Sélectionner le ou les responsables pour filtrer les factures q
u'ils gèrent.
3. Mode de Mise à Jour Comptable
Options de mise à jour :
Par client : Génération d'une écriture comptable par client.
Par n° provisoire : Génération d'une écriture comptable par numéro provisoire.
Avec mise à jour : Permet de générer une écriture comptable.
Sans mise à jour : Aucune écriture comptable ne sera générée.
Rédédition : Rééditer une facture existante.
Date de facture : Sélectionner la date de la facture.
Code banque pour BVR : Indiquer le code de la banque pour le BVR (Bulletin de Ve
rsement avec Référence).
4. Sélection de la Demande d'Acompte à Traiter
Liste des factures : Afficher les factures non imputées ou imputées. Vous pouvez
 sélectionner les factures à traiter dans cette liste.
5. Lot de Comptabilisation
Choisir/créer le lot : Cliquer sur l'icône pour choisir ou créer un lot pour la 
comptabilisation des factures.
6. Libellé des Écritures
Saisir le libellé : Entrer le libellé qui apparaîtra en comptabilité. Par défaut
, il peut être "facture" ou "NC" (Note de Crédit).
7. Impression de la Facture
Imprimer vers fichier : Cette option permet d'imprimer la facture vers un fichie
r. Cliquez sur l'icône d'imprimante pour lancer l'impression.
Variante fa662 :

NB : Cette variante est spécifique à certains clients

Le programme FA662 permet uniquement d' attribuer un numéro de facture et d'envo
yer le document à un client final (Edition).

Avantage : en cas de changement de montant, rabais etc.. il n'est pas nécessaire
 d'extourner l'écriture (pas de comptabilisation).

Exemple de flux :

1) FV100 : Création facture pour Fr. 200.-
2) FA662 : Edition de la facture (pas d'imputation)

Puis, le montant passe de Fr. 200.- à Fr. 140.-

3) FV100 : Modification du montant à Fr. 140.-
4) FA661 : Edition de la facture avec mise à jour => la facture est imputée en c
omptabilié
Tables simple facturation fa900 :

Note explicative des tables simple de facturation programme « fa900 » : 
Le programme "fa900" est utilisé pour gérer les tables simples dans le système E
RP. Voici une description détaillée de sa composition et de son fonctionnement :
1. Types de Tables
Sur la partie gauche de l'écran, vous avez une liste de types de tables que vous
 pouvez gérer. Dans cet exemple, nous voyons deux types :
lab : Labels variables factures
rab : Types de rabais
Vous pouvez sélectionner le type de table que vous souhaitez afficher et modifie
r.
2. Liste des Éléments
Au centre de l'écran, vous avez une vue tableau des éléments de la table sélecti
onnée. Cette vue affiche :
No Code : Le code unique de l'élément dans la table.
Désignation : La désignation principale de l'élément.
Désignation 2 : Une désignation supplémentaire pour l'élément.
3. Détails de l'Élément Sélectionné
Lorsque vous sélectionnez un élément dans la liste, ses détails apparaissent dan
s la section inférieure de l'écran :
Langue : Sélectionnez la langue associée à l'élément.
Numéro : Le numéro unique de l'élément.
Code : Le code de l'élément.
Désignation (1) : La première désignation ou description de l'élément.
Désignation (2) : Une deuxième désignation ou description pour des informations 
supplémentaires.
Divers : Champ libre pour des informations diverses sur l'élément.
Texte Swissdec : Un texte spécifique lié à Swissdec pour cet élément.
Utilisation
Pour utiliser le programme "fa900" :
Sélectionnez un type de table dans la liste de gauche.
Visualisez les éléments de cette table dans la vue tableau au centre.
Sélectionnez un élément pour en voir les détails et les modifier si nécessaire.
Utilisez les boutons en bas pour ajouter, enregistrer, copier ou effacer les élé
ments de la table.
