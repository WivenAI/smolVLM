iode sélectionnée.
Cumul Crédits : Affiche le total des crédits enregistrés sur le compte pour la p

Note explicative de la recherche et édition d’une écriture programme « co340 » :
 

Le programme "co340" est conçu pour rechercher et éditer des écritures comptable
s spécifiques dans le système ERP. Il permet de localiser rapidement une écritur
e en fonction de divers critères et d'apporter les modifications nécessaires. Vo
ici une explication détaillée de la composition et des fonctionnalités de ce pro
gramme.
1. Critères de Recherche
Sélection des Critères : Vous pouvez choisir le critère de recherche en utilisan
t les options suivantes :
Par N° d'écriture : Recherche basée sur le numéro unique de l'écriture.
Par type de compte, N° de pièce : Recherche par combinaison du type de compte et
 du numéro de pièce.
Par type de compte, type de journal : Recherche par combinaison du type de compt
e et du type de journal.
Par date valeur comptable : Recherche basée sur la date de valeur comptable de l
'écriture.
2. Sélection de l'Exercice
Exercice : Menu déroulant permettant de sélectionner l'exercice comptable pour l
equel vous souhaitez effectuer la recherche. Cela limite la recherche aux écritu
res enregistrées durant l'exercice choisi.
3. Inclusion des Écritures Effacées
Écriture(s) Effacée(s) : Case à cocher qui, lorsqu'elle est activée, inclut les 
écritures effacées dans les résultats de recherche. Cela permet de retrouver et 
d'examiner des écritures supprimées ou annulées.
4. Saisie du Numéro d'Écriture
N° d'Écriture : Champ de saisie permettant d'entrer directement le numéro de l'é
criture que vous souhaitez rechercher. Ce champ est particulièrement utile si vo
us connaissez déjà le numéro précis de l'écriture.
5. Validation
Bouton "OK" : Bouton pour valider les critères de recherche et lancer la recherc
he des écritures correspondantes dans le système. Après validation, les résultat
s s'affichent dans le tableau principal.
6. Visualisation et Impression
Bouton Imprimer/Visualiser : Situé en bas à gauche, ce bouton permet de visualis
er ou d'imprimer les résultats de la recherche. Cela est utile pour conserver un
e trace des écritures consultées ou modifiées.
Utilisation Pratique
Définir les Critères de Recherche
Sélectionnez le critère de recherche approprié en fonction des informations dont
 vous disposez (numéro d'écriture, type de compte, etc.).
Choisir l'Exercice Comptable
Utilisez le menu déroulant pour choisir l'exercice comptable dans lequel vous so
uhaitez rechercher des écritures.
Inclure les Écritures Effacées
Si vous devez rechercher des écritures qui ont été effacées, cochez la case "Écr
iture(s) effacée(s)".
Saisir le Numéro d'Écriture
Si vous connaissez le numéro exact de l'écriture, entrez-le dans le champ dédié 
pour accéder directement à cette écriture.
Valider et Visualiser
Cliquez sur "OK" pour afficher les écritures correspondant à vos critères.
Utilisez le bouton "Imprimer/Visualiser" pour examiner ou imprimer les résultats
 de votre recherche.

En résumé, le programme "co340" est un outil essentiel pour la gestion des écrit
ures comptables, offrant une interface intuitive pour la recherche et l'édition 
des écritures dans le système ERP. Il permet de trouver rapidement des écritures
 spécifiques et de les modifier si nécessaire, tout en offrant la possibilité de
 gérer également les écritures effacées.
