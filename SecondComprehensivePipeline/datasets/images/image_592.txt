Note explicative de la gestion des offres programme « of110 » : 

Le programme "of110" est utilisé pour la gestion des offres. Il permet de suivre
 et de gérer les offres commerciales émises par l'entreprise. Voici une explicat
ion détaillée de sa composition et de son fonctionnement :
1. Filtre des genres d'offres
Cette section permet de filtrer les offres selon leur genre :
Type de facture : Sélectionner le type d'offre à afficher, comme "Offre simple",
 "Offre complexe", etc.
2. Filtre par dates
Permet de filtrer les offres en fonction de la période spécifiée :
Factures du : Définir une plage de dates pour filtrer les offres en fonction de 
leur date de création ou de leur date de validation.
3. Panneau de commandes spécifique
Ce panneau contient diverses commandes pour gérer les offres :
Ajouter, Modifier, Supprimer : Permet d'ajouter une nouvelle offre, de modifier 
une offre existante ou de supprimer une offre.
Sauvegarder, Annuler : Enregistrer les modifications apportées à une offre ou an
nuler les modifications non enregistrées.
4. Sélection par utilisateur
Permet de filtrer les offres selon l'utilisateur :
Mes factures : Affiche les offres créées par l'utilisateur connecté.
Toutes les factures : Affiche toutes les offres, indépendamment de l'utilisateur
 qui les a créées.
5. Historique des demandes d'acompte
Cette section affiche l'historique des demandes d'acompte associées à l'offre sé
lectionnée :
Acomptes : Détaille les acomptes demandés et leur statut (validé, en attente, et
c.).
6. Statut actuel de l'offre
Affiche le statut actuel de l'offre sélectionnée :
Statut : Indique si l'offre est validée, en attente de validation, refusée, etc.
Date de valeur : Date de la dernière mise à jour du statut de l'offre.
7. Filtre selon statut
Permet de filtrer les offres en fonction de leur statut :
Factures non imputées, Imputées, Toutes : Filtrer les offres selon qu'elles soie
nt encore à traiter, déjà traitées ou afficher toutes les offres.

on du plan comptable. Voici une description détaillée de ses composants et fonct
ionnalités pour une compréhension claire et exhaustive :
1. Volet de Visualisation du Compte
Le volet de visualisation du compte est une section du programme où l'utilisateu
r peut sélectionner et afficher les détails d'un compte spécifique. Cela permet 
de voir en un coup d'œil les informations essentielles d'un compte comptable, y 
compris les transactions et les soldes actuels.
2. Solde Actuel du Compte
Le solde actuel du compte est une information cruciale affichée en haut de la fe
nêtre. Il indique le montant disponible ou dû dans le compte sélectionné. Cette 
valeur est mise à jour en temps réel en fonction des transactions enregistrées d
ans le système.
3. Onglet "Liste"
L'onglet "Liste" est une interface de visualisation où sont listés tous les comp
tes du plan comptable. Voici une description détaillée des colonnes et des infor
mations affichées :
Numéro : Le numéro unique attribué à chaque compte, utilisé pour l'identificatio
n et le suivi.
Intitulé court : Un nom abrégé du compte pour une identification rapide.
Monnaie : La devise dans laquelle les transactions du compte sont effectuées.
Type : Indique la nature du compte (Actif, Passif, etc.).
Intitulé : Le nom complet du compte, donnant plus de détails que l'intitulé cour
t.
Intitulé (suite) : Informations supplémentaires ou descriptions étendues du comp
te.
Compte C.A. : Référence au compte de Centre d'Analyse (C.A.) si applicable.
Genre de frais : Type de dépenses associées au compte, le cas échéant.
Fonctionnalités Clés :
Navigation et Sélection :
Type de compte : Un filtre permettant de sélectionner un type de compte spécifiq
ue pour une visualisation plus ciblée.
Saisie du compte : Une zone de saisie pour entrer directement le numéro de compt
e que l'utilisateur souhaite consulter.
Visualisation des Soldes :
Soldes actuels en monnaie : Affiche le solde actuel dans la devise principale du
 compte.
En contre-valeur : Montre la valeur équivalente dans une autre devise, facilitan
t ainsi les opérations multicurrency.
Gestion des Comptes :
Hist-lettre : Onglet permettant l'accès à l'historique des lettrages, important 
pour les réconciliations bancaires et autres ajustements comptables.

Note explicative de l’onglet « Compte » du plan comptable programme « cg100 » :

L'onglet "Compte" du programme "cg100" est conçu pour permettre une gestion déta
illée et complète des comptes du plan comptable. Voici une explication fonctionn
elle et détaillée des différents composants et fonctionnalités de cet onglet.
1. Paramètres de Base du Compte
Cette section permet de configurer les informations fondamentales du compte séle
ctionné.
Compte : Zone de saisie du numéro de compte.
Intitulé de recherche : Description ou libellé du compte pour faciliter les rech
erches.
Intitulé : Libellé principal du compte pour une identification claire.
Intitulé (suite) : Informations complémentaires sur le compte.
Monnaie : Devise utilisée pour les transactions de ce compte.
Pays TVA : Pays d'application de la TVA pour ce compte.
2. Paramètres de Comptabilité Analytique
Cette section est dédiée à la configuration des aspects analytiques du compte.
Compte C.A. : Sélection ou saisie du compte de Centre d'Analyse.
Genre de frais : Spécifie la nature des frais associés à ce compte.
Analyse des flux financiers : Permet de définir et de gérer les groupes de flux 
financiers pour une analyse détaillée.
3. Sélections Spéciales et Blocage du Compte
Cette zone permet d'appliquer diverses sélections spéciales et options de blocag
e pour le compte.
A imprimer : Indique si le compte doit être inclus dans les impressions.
Comptabilisation bloquée : Empêche les nouvelles écritures comptables sur ce com
pte.
Ne sera pas reporté : Exclut le compte des reportings financiers.
Est un compte transfert de fonds : Identifie le compte comme étant utilisé pour 
les transferts de fonds.
Autres options : Plusieurs autres cases à cocher pour spécifier des utilisations
 particulières ou des restrictions pour ce compte (par exemple, détail des salai
res, comptes clients/fournisseurs).
4. Choix du Type de Compte
Cette section permet de définir le type de compte parmi plusieurs options.
Actif : Compte d'actif.
Passif : Compte de passif.
Produit : Compte de produits.
Charge : Compte de charges.
Changement de classe : Options pour changer la classification du compte.
Tampon : Utilisé pour des comptes temporaires ou de transition.
N'est pas un compte collectif : Spécifie si le compte est individuel ou collecti
f (clients, fournisseurs).
5. Paramétrage de l'Accès aux Données
Permet de gérer les droits d'accès et les niveaux de permission pour les utilisa
teurs concernant ce compte spécifique.
