Le programme db100, dédié à la gestion des débiteurs, comporte un onglet "Compte

Détails du Compte :
Numéro : Le numéro identifiant unique du débiteur dans le système.
Intitulé de recherche : Un titre ou une référence rapide utilisée pour identifie
r le débiteur lors des recherches.
Numéro d'adresse : Numéro spécifique attribué à l'adresse du débiteur.
Monnaie : La monnaie dans laquelle les transactions du débiteur sont gérées.
Conditions de paiement : Conditions sous lesquelles les paiements sont acceptés 
de ce débiteur.
T.V.A. : Informations sur la taxe sur la valeur ajoutée applicable, y compris si
 la taxe est incluse, et autres spécificités relatives à l'organisation internat
ionale.
Gestion de Groupe et Collectif :
Collectif : Catégorie de collectif à laquelle le débiteur appartient, avec une o
ption pour changer de collectif si nécessaire.
Groupe clients : Groupe auquel le débiteur est associé pour faciliter la gestion
 segmentée.
Sucursale : Branche ou division de l'entreprise à laquelle le débiteur est assoc
ié.
Groupe statistique : Groupe pour lequel des données statistiques sont collectées
.
Détails de Facturation :
Adresse de facturation : Où les factures doivent être envoyées.
Tarif : Identifie le tarif spécifique appliqué au débiteur.
BVR : Numéro de référence pour le bulletin de versement (utilisé en Suisse).
Factures PDF : Si les factures doivent être générées en format PDF.
Factures groupées : Indique si les factures pour ce débiteur doivent être groupé
es.
Gestion des Risques et Crédits :
Limite de crédit : Montant maximal de crédit autorisé pour ce débiteur.
Options Additionnelles :
Édition des appels par chantier : Détermine si les appels de paiement doivent êt
re spécifiques à chaque chantier.
Est un compte de regroupement : Indique si le compte est utilisé pour regrouper 
plusieurs débiteurs sous une seule entité pour la facturation ou les rapports.
